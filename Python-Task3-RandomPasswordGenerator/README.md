# Random Password Generator

## Description
This project is a Python-based Random Password Generator that creates a random password according to the length entered by the user.

## Features
- Accepts password length from the user
- Generates random characters
- Includes uppercase and lowercase letters
- Includes numbers
- Includes special characters
- Handles invalid input

## Technologies Used
- Python
- random module
- string module

## How to Run
1. Open the terminal.
2. Navigate to the project folder.
3. Run:
   `py password_generator.py`
4. Enter the required password length.
