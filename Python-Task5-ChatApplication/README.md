# Task 5 - Chat Application

## Description
A simple Python-based chat application using socket programming.

## Files
- client.py - Chat client program
- server.py - Chat server program

## Technology Used
- Python
- Socket Programming

## How to Run
1. Run `server.py` first.
2. Then run `client.py`.
3. Enter your name.
4. Start chatting.

## Output
The client connects to the server and allows users to send and receive messages.
