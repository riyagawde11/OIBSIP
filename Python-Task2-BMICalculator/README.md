# Task 1 - BMI Calculator

## Description
A simple Python program to calculate Body Mass Index (BMI) based on the user's weight and height.

## Features
- Takes weight in kilograms
- Takes height in meters
- Calculates BMI
- Displays BMI category
- Handles invalid input

## Technologies Used
- Python

## How to Run
1. Open the project in VS Code.
2. Run `bmi_calculator.py`.
3. Enter your weight in kg.
4. Enter your height in meters.
5. The program displays your BMI and category.

## Example

Enter your weight in kg: 60  
Enter your height in meters: 1.65  

Your BMI is: 22.04  
Category: Normal weight
